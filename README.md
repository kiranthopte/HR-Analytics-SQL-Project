HR Analytics Using SQL | Employee Database Analysis
This project focuses on analyzing Human Resources (HR) data using SQL. The objective is to generate business insights related to employee management, salary distribution, department performance, reporting hierarchy, and workforce analytics. Project uses multiple SQL techniques including joins, aggregations, subqueries, CTEs, and window functions
Database Tables Used
Employees
Departments
Jobs
Dependents
Locations
Countries
Business Problems Solved
Employee & Department Analysis
Display employees with their department names.
Identify employees without assigned departments.
Count employees department-wise.
Salary Analysis
Find employees earning more than a specified amount.
Compare salaries against company-wide average salary.
Compare salaries against department-wise average salary.
Analyze salary distribution using percentile rankings.
Department Insights
Calculate average salary by job title.
Identify top-paid employees within each department.
Measure percentage of employees earning above minimum job salary.
Organizational Hierarchy Analysis
Identify employees without managers.
Analyze manager-subordinate relationships.
Calculate average salary of employees reporting to each manager.
Workforce Analytics
Find employees with dependents.
Analyze employee distribution across countries.
Track hiring trends based on joining dates.
